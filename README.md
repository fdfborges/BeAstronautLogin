# 🚀 BeAstronaut

> Uma interface de login inspirada no universo espacial, criada para praticar HTML, CSS, formulários e responsividade.

## 🌌 Sobre o projeto

**BeAstronaut** é um projeto de estudo focado na construção de uma interface de autenticação com estética espacial.

A proposta combina uma tela de login limpa com um painel visual inspirado em exploração espacial, trabalhando composição, hierarquia visual e adaptação para diferentes tamanhos de tela.

O projeto está sendo desenvolvido de forma incremental. Nesta primeira versão, o foco está na **tela de login** e na prática de fundamentos de Front-End.

## ✨ Funcionalidades

- 🔐 Formulário de login
- 📧 Campo de e-mail com validação nativa do HTML
- 🔑 Campo de senha
- 👁️ Visualização/ocultação da senha
- ☑️ Opção "Lembrar senha"
- 🔗 Recuperação de senha
- 🌐 Opções de login social
- 📱 Layout responsivo
- 🎨 Interface inspirada em exploração espacial
- 🪐 Elementos decorativos e efeitos visuais

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript
- SVG
- Git & GitHub

## 📱 Responsividade

A interface foi desenvolvida para se adaptar a diferentes tamanhos de tela.

## 🎯 Objetivos de aprendizado

Este projeto foi criado para praticar:

- Estruturação de formulários com HTML
- Uso de `label`, `input` e atributos de formulário
- Validação nativa com HTML
- CSS e organização visual
- Responsividade e Media Queries
- Posicionamento e sobreposição de elementos
- Uso de imagens e SVGs
- Efeitos de blur e overlays
- Organização de um projeto Front-End
- Git e GitHub

Abra o projeto com o **Live Server** no VS Code.
